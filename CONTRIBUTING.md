# Contributing to TIEFGANG

Thanks for wanting to help! TIEFGANG is a solo project in active development, and feedback from players directly shapes
what comes next.

The game's source code is not public, so code contributions and pull requests aren't possible. What helps most:

## Report bugs

Open an issue with the **[bug report form](https://github.com/OsuGerman/Tiefgang-Releases/issues/new/choose)**.
A good report has:

- the **game version** (shown in the main menu),
- **what you did** and **what happened**, step by step,
- a **screenshot or short video**, if you can,
- the **log file** for crashes: `%APPDATA%\Godot\app_userdata\TIEFGANG\logs` (the newest `godot*.log`),
- your **hardware** for performance problems: CPU, GPU, RAM, resolution and graphics preset.

Please check the [open issues](https://github.com/OsuGerman/Tiefgang-Releases/issues) first. If your bug is already
there, a comment with extra details is more useful than a new issue.

## Share feedback and ideas

Honest feedback is welcome, good or bad: what felt great, what felt boring, which weapon you never use, where you got
lost. You can post it as an issue, or as a comment on the [itch.io page](https://osugerman.itch.io/tiefgang).

## Make videos and streams

You're welcome to stream TIEFGANG and publish videos of it, including monetized ones. See [LICENSE](LICENSE) for
details.

## Security problems

Please don't post them publicly. See [SECURITY.md](SECURITY.md).

## Be kind

Be respectful to other players and testers. Personal attacks, harassment and spam will be removed.
