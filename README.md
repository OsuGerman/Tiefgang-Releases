# TIEFGANG – Test-Builds

Unterwasser-Roguelike-Shooter (Godot 4.7, Windows). Hier liegen die Test-Builds zum Ausprobieren.

## Installieren
1. Unter **[Releases](https://github.com/OsuGerman/Tiefgang-Releases/releases/latest)** die Datei `Tiefgang-Windows.zip` herunterladen.
2. Den Ordner `Tiefgang` entpacken – irgendwohin, wo du schreiben darfst (Desktop, Dokumente). **Nicht** nach `C:\Programme`, sonst funktioniert das Auto-Update nicht.
3. `Tiefgang.exe` starten. Falls Windows „Der Computer wurde durch Windows geschützt“ meldet: **Weitere Informationen → Trotzdem ausführen** (der Build ist nicht signiert).

## Updates
Das Spiel prüft beim Start im Hauptmenü, ob es einen neueren Test-Build gibt, und zeigt dann unten rechts **„Jetzt aktualisieren“**. Es lädt das Update, beendet sich, ersetzt die Dateien im Ordner und startet neu. Spielstände bleiben erhalten. Ohne Internet startet das Spiel normal, nur ohne Update-Hinweis.

## Feedback
Fehler und Eindrücke bitte als **[Issue](https://github.com/OsuGerman/Tiefgang-Releases/issues)** melden – am besten mit Gebiet/Tiefe, was passiert ist und der Versionsnummer (unten rechts im Hauptmenü).

## Voraussetzungen
Windows 10/11 (64 Bit), Grafikkarte mit Vulkan-Unterstützung, ca. 1 GB freier Speicher.
