# Security policy

TIEFGANG has a few online features: the in-game updater, the online leaderboard, the player counter and co-op
matchmaking. If you find a way to abuse one of them, for example to break the leaderboard, crash other players in
co-op or make the updater run something it shouldn't, please report it privately.

## How to report

- Use **[Report a vulnerability](https://github.com/OsuGerman/Tiefgang-Releases/security/advisories/new)** here on
  GitHub (Security tab). Only the maintainer can see these reports.
- **Please don't open a public issue** for security problems, so it can be fixed before others can abuse it.

Helpful details: what you did, what happened, the game version (shown in the main menu) and, if possible, a short
video or the log file (`%APPDATA%\Godot\app_userdata\TIEFGANG\logs`).

## What happens next

This is a solo project, so there is no fixed response time, but security reports come first. You'll get a reply as
soon as possible, and the fix ships with the next update through the in-game updater.

## Supported versions

Only the **latest release** gets fixes. The in-game updater keeps you on it automatically.

Gameplay bugs and crashes that don't affect other players are not security issues. Please report them with the
[bug report form](https://github.com/OsuGerman/Tiefgang-Releases/issues/new/choose).
