    Frisch aus der TiefeFresh from the Deep

    Koop für bis zu vier, drei Gebiete im neuen Grafik-Standard, neu gemachte Element-Effekte, 25 neue Gegnerangriffe, eine eigene Mechanik für jede Waffe und neue Menüs samt HUD und Logbuch. Alles Weitere steht im Changelog.

    Co-op for up to four, three areas rebuilt to the new graphics standard, redone element effects, 25 new enemy attacks, a mechanic of its own for every weapon, and new menus with a new HUD and logbook. The rest is in the changelog.

    Installation

    1. Tiefgang-Windows.zip herunterladen – oder über itch.io. Ältere Versionen unter Releases.
    2. Ordner „Tiefgang“ entpacken – dorthin, wo du schreiben darfst, z. B. Desktop oder Dokumente. Nicht nach „C:\Programme“, sonst klappt das Auto-Update nicht.
    3. Tiefgang.exe starten. Meldet Windows „Der Computer wurde durch Windows geschützt“: Weitere Informationen → Trotzdem ausführen (der Test-Build ist nicht signiert).
    1. Download Tiefgang-Windows.zip – or grab it on itch.io. Older versions are under Releases.
    2. Extract the “Tiefgang” folder somewhere you can write to, such as Desktop or Documents. Not into “C:\Program Files”, or the auto-update won’t work.
    3. Run Tiefgang.exe. If Windows says “Windows protected your PC”: More info → Run anyway (the test build is not signed).

    Auto-Update

    Das Spiel lädt neue Test-Builds automatisch im Hintergrund (abschaltbar unter Einstellungen → Gameplay) und installiert sie nur im Hauptmenü, beim Beenden oder beim nächsten Start – nie mitten im Run. Spielstände bleiben erhalten. Ohne Internet startet das Spiel ganz normal.

    The game downloads new test builds in the background (can be turned off under Settings → Gameplay) and installs them only in the main menu, on quitting or at the next start – never mid-run. Your saves are kept. Without internet the game simply starts as usual.
